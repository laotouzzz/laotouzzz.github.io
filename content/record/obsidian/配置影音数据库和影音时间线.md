说明：
- `00-assets/{{type}}`：附件文件夹自动保存。举例：`00-assets/movie/军舰岛.webp`
- `01-书影音记录/{{type}}/{{title}}`：为电影笔记文件保存位置。举例：`01-书影音记录/movie/军舰岛.md

# timeline-插件设置
首先在dateview插件打开如下选项
![](/record/obsidian/00-assets/assets-20260509-205326.jpg)
新建md文件输入一下代码：
```
// ================= 配置区 =================
// 在这里设置你想限制的“观看年份”，比如 2025
const targetYear = 2026; 
// ==========================================

// 1. 筛选带有 movie 标签且具有“观看日期”属性的笔记
let pages = dv.pages("#movie").where(p => {
    // 如果没有观看日期，直接排除
    if (!p.观看日期) return false;
    
    // 如果配置了目标年份，进行严格比对
    if (targetYear !== null) {
        let viewYear;
        // 兼容处理：判断它是 Dataview 的日期对象，还是普通文本字符串
        if (p.观看日期.year) {
            viewYear = p.观看日期.year; 
        } else {
            viewYear = moment(p.观看日期.toString()).year(); 
        }
        
        // 如果观看日期的年份不等于目标年份，排除
        if (viewYear !== targetYear) return false;
    }
    
    return true; 
});

// 2.按观看日期进行排序（'asc' 为升序，即从早到晚；改为 'desc' 则是从晚到早）
pages = pages.sort(p => p.观看日期, 'desc');

// 3. 构建 timeline-labeled 格式的字符串文本
let timelineText = "```timeline-labeled\n[line-3, body-2]\n";

for (let page of pages) {
    // 提取属性
    let date = page.观看日期 ? moment(page.观看日期.toString()).format("YYYY-MM-DD") : "未知日期";
    let title = page.电影名称 || page.file.name;
    let score = page.评分 || "暂无";
    let desc = page.简介 || "暂无简介";
    let type = page.类型 || "电影"; 
    
    // 4. 自动拼接海报路径（保持之前的紧凑设置）
    // 400为海报的尺寸大小，可随意设置
    let imagePath = `00-assets/${type}/2026/${title}.webp`;
    let posterHtml = `![[${imagePath}|400]]<br>`;

    // 5. 【新增】构建指向原始笔记的内部链接
    // 使用 page.file.name 确保链接指向正确的文件，并加上一个图标美化
    let sourceLink = `[[${page.file.name}|📂 查看原文]]`;

    // 6. 按照语法规则拼接：在 content 的最后加上链接
    timelineText += `date: ${date}\n`;
    timelineText += `title: ${title}\n`;
    // 使用 <br><br> 在简介和链接之间留出一点视觉间距
    timelineText += `content: \n${posterHtml}**评分:** ${score} <br> **简介:** ${desc} <br><br> ${sourceLink}\n\n`;
}

timelineText += "```";

// 7. 渲染到页面
dv.paragraph(timelineText);
```
注意：在此处添加如下字段：`dataviewjs`
代码部分不添加因为会自动预览，所以暂时删除
