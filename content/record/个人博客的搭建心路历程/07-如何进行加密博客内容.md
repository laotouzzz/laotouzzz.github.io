很好，既然你用的是 **Blowfish**，我们现在可以把集成方案确定下来，而且不需要修改 `themes/blowfish/`。

我已经专门给你重新整理了一份 **Blowfish 适配版**：

[下载 Blowfish + Meld Encrypt 解锁组件](sandbox:/mnt/data/hugo-meld-unlock-blowfish.zip)

当前 Blowfish 的单篇文章模板确实把正文放在：

```html
<div class="article-content max-w-prose mb-20">
  {{ .Content }}
</div>
```

所以我们的 JS 已经能够准确扫描文章正文，不需要覆盖 `single.html`。

同时 Blowfish 官方明确提供 `extend-head.html` 和 `extend-footer.html` 用于加载自定义 CSS/JS，并且官方建议**不要直接修改主题目录**，这样升级主题不会覆盖你的修改。([Blowfish][1])

## 1 现在按下面步骤操作

### 1.1 解压新版文件

[点击前往蓝奏云下载](https://yulaotou.lanzoul.com/imGVz43mcr0j)

里面最重要的是：

```text
assets/
├── css/
│   └── meld-encrypt.css
└── js/
    └── meld-encrypt.js

layouts/
└── partials/
    ├── meld-encrypt-head.html
    └── meld-encrypt-footer.html
	├── extend-head.html
	├── extend-footer.html
```

把这些目录复制到你的 Hugo 博客**根目录**。

比如你的博客现在：

```text
my-blog/
├── config/
├── content/
├── themes/
│   └── blowfish/
└── ...
```

复制之后变成：

```text
my-blog/
├── assets/
│   ├── css/
│   │   └── meld-encrypt.css
│   └── js/
│       └── meld-encrypt.js
│
├── layouts/
│   └── partials/
│       ├── meld-encrypt-head.html
│       └── meld-encrypt-footer.html
│       ├── extend-head.html
│       ├── extend-footer.html
│
├── content/
├── config/
└── themes/
    └── blowfish/
```

特别注意：

```text
❌ themes/blowfish/layouts/...
```

不要修改。

Blowfish 官方也推荐把自己的覆盖和扩展放在 Hugo 项目根目录，而不是 theme 本身。([Blowfish][2])

## 2 安装 markdown-it

进入你的 Hugo 博客根目录：

```bash
cd 你的博客目录
```

执行：

```bash
npm install --save-dev markdown-it
```

然后：

```bash
mkdir -p assets/vendor
```

macOS / Linux：

```bash
cp node_modules/markdown-it/dist/markdown-it.min.js \
  assets/vendor/markdown-it.min.js
```

Windows PowerShell：

```powershell
New-Item -ItemType Directory -Force assets/vendor
 
Copy-Item `
  "node_modules\markdown-it\dist\browser\markdown-it.umd.min.js" `
  "assets\vendor\markdown-it.min.js"
```

完成以后应该有：

```text
assets/
├── css/
│   └── meld-encrypt.css
├── js/
│   └── meld-encrypt.js
└── vendor/
    └── markdown-it.min.js
```

这里和上一版不一样：

之前我让你放：

```text
static/vendor/
```

**Blowfish 专版改成了：**

```text
assets/vendor/
```

因为我们现在直接利用 Blowfish/Hugo 的 asset pipeline 做 fingerprint。

## 5 为什么 Blowfish 不需要额外配置正文 selector

因为当前 Blowfish `single.html` 的正文明确是：

```html
<div class="article-content max-w-prose mb-20">
    {{ .Content }}
</div>
```



而我给你的 `meld-encrypt.js` 已经包含：

```js
articleSelectors: [
  '.post-content',
  '.article-content',
  '.post-single .post-content',
  'article .content',
  'article',
  'main'
]
```

所以在 Blowfish：

```text
.article-content
        ↓
被找到
        ↓
只扫描文章正文
        ↓
发现 🔐β
        ↓
生成解锁 UI
```

这一点现在已经匹配好了。

## 6 输入正确密码

输入 Obsidian Meld Encrypt 使用的密码。

浏览器执行的仍然是你旧解密器已经采用的核心逻辑：

```text
Password
    ↓
PBKDF2
SHA-512
210000 iterations
    ↓
AES-256 key
    ↓
AES-GCM
    ↓
Markdown plaintext
```

你旧工具里的 β 参数映射就是 `SHA-512 / 210000`。

然后：

```text
Markdown
    ↓
markdown-it
    ↓
HTML
```

页面就会显示：

```text
🔓 已解锁                     重新锁定

私密测试

如果你输入正确密码后能够看到这里，
说明 Blowfish + Meld Encrypt 已经部署成功。

这里有 粗体。

• Apple
• Banana
• Orange
```

## 7 Blowfish 深色模式也可以

Blowfish 自己有：

```text
light
dark
auto
```

模式，而且正文使用 `prose / dark:prose-invert` 这一套样式。当前文章模板同样能看到这一结构。

我给你的 CSS 已经尽量采用 CSS variables / 半透明边框设计，所以：

```text
☀ Light mode
🌙 Dark mode
```

都可以工作。

等你跑起来后，如果你希望加密框更加“原生 Blowfish 风格”，下一版我们还可以进一步做到：

```text
完全使用 Blowfish primary color
跟随 Blowfish colorScheme
按钮使用主题 primary-500
暗色模式完全一致
锁 icon 使用 Blowfish 自带 SVG icon
```

第一版先以功能正确为主。

## 8 最重要的一次安全验证

假设私密正文有一句：

```text
说明 Blowfish + Meld Encrypt 已经部署成功
```

加密以后运行：

```bash
grep -R -nF \
  "说明 Blowfish + Meld Encrypt 已经部署成功" \
  content/
```

应该：

```text
没有输出
```

然后：

```bash
hugo
```

继续：

```bash
grep -R -nF \
  "说明 Blowfish + Meld Encrypt 已经部署成功" \
  public/
```

也应该：

```text
没有输出
```

线上打开网页后：

```text
右键
→ 查看网页源代码
```

搜索同一句话。

也应该：

```text
找不到
```

这三个检查都通过，才说明你的：

```text
Obsidian
→ Git
→ Hugo
→ GitHub Pages
```

整个链路里没有私密明文。
