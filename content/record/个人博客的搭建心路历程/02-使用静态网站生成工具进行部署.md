## 静态网站生成工具
我们需要的页面肯定不是只有一行文本的，希望其更加的丰富，其实GitHub Pages支持多种静态网站生成工具。[参考文档](https://blog.csdn.net/qq_20042935/article/details/133920722)

以下是一些GitHub Pages支持的主要静态网站生成工具：

[Jekyll](https://jekyllrb.com)：Jekyll是GitHub Pages的默认静态网站生成工具，它使用Markdown文件和Liquid模板引擎来创建静态网站，Jekyll对于博客和文档站点非常流行。

[Hugo](https://gohugo.io/)：Hugo是另一个受欢迎的静态网站生成工具，它非常快速且易于使用，它使用Go语言编写，支持多种主题和内容组织方式。

[Gatsby](https://www.gatsbyjs.com/)：Gatsby是基于React的静态网站生成工具，它可以构建高性能、现代化的网站，Gatsby适用于博客、电子商务、应用程序文档等。

[VuePress](https://vuepress.vuejs.org/)：VuePress是Vue.js驱动的静态网站生成工具，专注于文档站点，它支持Markdown文件和Vue组件。

[Hexo](https://hexo.io/)：Hexo是一个快速、简单的博客框架，使用Markdown文件来生成静态博客，它是Node.js应用程序。

[Pelican](https://blog.getpelican.com/)：Pelican是使用Python编写的静态网站生成器，适用于博客和文档。

[Middleman](https://middlemanapp.com/)：Middleman是Ruby编写的静态网站生成工具，支持多种模板和数据源，适用于各种项目。

[Sphinx](https://www.sphinx-doc.org/)：Sphinx是一个Python文档生成工具，通常用于技术文档和文档站点。

[MkDocs](https://www.mkdocs.org)：MkDocs是Python编写的文档生成工具，使用Markdown文件创建文档站点。


## 选择Hugo

在静态博客程序中可供选择的非常多，Hugo 是我最终的选择：使用 Markdown 写作、社区非常活跃、构建静态网站的速度非常快！

## 开始
### 安装Hugo
[Hugo文档](https://gohugo.io/installation/)提供了详细的安装指南

下载Windows版本-点击下载[⏬官方最新版](https://github.com/gohugoio/hugo/releases/latest)

>主要有三种版本
>
>- `hugo_0.165.0_windows‑amd64.zip`（标准版）
>
>普通基础版本，**没有Sass/SCSS编译支持**，很多现代Hugo主题会报错样式失效，不推荐新手用。
>
>- `hugo_extended_0.165.0_windows‑amd64.zip`（**下载这个！**）
>
>Extended扩展版，包含Sass处理，绝大多数Hugo主题依赖这个，本地预览主题不会出现样式丢失。其中带有withdeploy功能是用来直接部署到AWS S3、阿里云OSS这类云存储桶，部署GitHub Pages完全用不到。
>
>- `hugo_withdeploy_0.165.0_windows‑amd64.zip`
>
>带云存储直接部署能力，不需要，GitHub Pages靠Actions推送，用不上这个功能。

### 下载完成简短操作

1. 解压
2. 放到文件夹例如`D:\hugo`，将这个目录添加到系统PATH环境变量
3. 打开PowerShell输入：
```powershell
hugo version
```
输出示例（看到 `extended` 就正常）
```
hugo v0.165.0-xxxx+extended windows/amd64
```

## 新建hugo网站项目
找一个空的本地文件夹，比如 `D:\code\hugo-site`
在PowerShell cd进到这个目录，执行：
```powershell
hugo new site homepage
```
执行完会生成 `homepage` 文件夹，可随意更改，这就是你的网站工程。

进入项目目录
```powershell
cd homepage
```

然后就会`homepage`文件夹生成如下树形结构

```
├── archetypes/
├── assets/
├── content/
├── data/
├── i18n/
├── layouts/
├── static/
└── themes/
```

## 简单配置
因为我是手动安装，`blowfish`在根目录`themes/`目录下
将`blowfish`文件下的`config`文件夹复制到项目网站`homepage`文件夹下，若有替代更换，直接替代即可

使用VS Code软件打开`homepage`，然后在终端运行
```powershell
hugo server
```
终端会输出地址：`http://localhost:1313`
浏览器打开这个地址，就能看到网站效果。
- 修改配置、写文章，网页会自动刷新。
- 按 `Ctrl + C` 停止服务。

现在的`homepage`的结构如下
```
├── archetypes/
├── assets/
├── config/
├── content/
├── data/
├── i18n/
├── layouts/
├── static/
├── public/  # 最终网站静态输出目录
├── resources/ # hugo 缓存资源目录，资源处理缓存
└── themes/
```
