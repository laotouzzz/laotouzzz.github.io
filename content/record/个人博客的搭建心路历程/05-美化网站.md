## 更换网站Logo
即页面顶部导航栏的左上角的网站 Logo

将logo图片放在`assets/img/logo.png`下面

在`languages.en.toml`参数下面找到`[params]`区域内容中的`image`参数改为
>`image = "img/logo.png"` # 浅色模式（白天主题）显示的导航栏 logo
>
>`secondaryLogo = "img/logo.png"` # 深色模式（夜间主题）显示的导航栏 logo

## 实现全屏背景

Blowfish 的首页背景和全站背景是两项不同的设置。`homepageImage` 只控制首页图片；如果希望文章页、文章列表页等页面也显示同一张全屏背景，需要在 Blowfish v3 中开启 `backgroundCanvas`。

### 准备背景图片

将背景图片放到 `assets/img/` 文件夹，例如 `assets/img/background.jpg`。

下面统一使用 `background.jpg`。如果使用官方的 SVG 背景，将图片放在 `assets/img/background.svg`，并把配置中的图片路径一起改成 `img/background.svg`。

### 开启全站固定背景（Blowfish v3）

打开 `config/_default/params.toml`，在文件顶层添加或修改下面两项。必须放在 `[header]`、`[homepage]` 等配置段之前，不能写在某个配置段里面。如果已有 `defaultBackgroundImage`，直接修改原来的值，不要重复添加。

```toml
# 全站默认背景图，路径相对于 assets 目录。
defaultBackgroundImage = "img/background.jpg"

# 开启全站固定全屏背景，让文章、栏目等页面也显示背景图。
backgroundCanvas = true
```

全站背景会叠加主题自带的遮罩，让正文更容易阅读。如果某篇文章单独配置了背景或封面，并使用背景式 Hero，页面可能优先显示文章自己的图片。

### 主页全屏背景

在同一个 `params.toml` 的 `[homepage]` 配置段中修改：

```toml
[homepage]
  # 首页使用整页背景布局。
  layout = "background"
  # 首页专用背景图；与全站背景使用同一路径，可以保持视觉一致。
  homepageImage = "img/background.jpg"
```

只设置 `homepageImage` 不会让其他页面自动使用首页图片，因此需要配合上面的全站背景设置。

### 单篇文章页面的背景式封面

开启全站背景后，文章页已有固定背景。如果还希望文章自己的封面以背景式 Hero 展示，在 `[article]` 配置段中修改：

```toml
[article]
  # 显示文章封面区域。
  showHero = true
  # 使用背景式封面。必须写小写 background，不能写 Background。
  heroStyle = "background"
```

`heroStyle` 控制封面的展示方式，`backgroundCanvas` 控制全站固定背景，两者用途不同。文章没有自己的封面时，开启的全站背景仍会显示。

### 文章列表页的背景式封面

如果希望栏目、文章列表页的封面也以背景形式展示，在 `[list]` 配置段中修改：

```toml
[list]
  # 显示列表页封面区域。
  showHero = true
  # 使用背景式封面，注意 background 必须全部小写。
  heroStyle = "background"
```

以上配置段如果已经存在，只修改里面的参数，不要重复添加 `[homepage]`、`[article]` 或 `[list]`。

### 重新构建并查看效果

在博客项目根目录运行：

```powershell
hugo --minify
```

如果需要在本机预览，运行 `hugo server`，打开终端显示的本地地址，分别查看首页、文章页和文章列表页。线上网站需要在重新部署后才会显示修改。

## 开启文章目录
在`params.toml`下`[article]`区域中改动
>`showHeadingAnchors = true`

若要控制目录从第几级标题开始显示，以及显示到第几级标题

在`markup.toml`下`[tableOfContents]`区域中改动
>`startLevel = 2` # 意思从二级标题开始显示
>
>`endLevel = 5` # 意思可以显示到五级标题

还有其他功能
在`params.toml`下检索改动
>`smartTOC = true` # 智能目录：阅读到哪个标题，就高亮哪个目录项
>
>`smartTOCHideUnfocusedChildren = false` # 是否隐藏当前阅读区域以外的深层目录。false 会保留完整目录。true会自动隐藏深层目录
