## 嵌入网页
可以通过 `<iframe>` 嵌入。对于你的 Hugo 管理器，建议做成一个自定义短代码，以后在 Markdown 中写一行就能预览网站，也不需要开启全局 HTML。

### 1. 创建网页预览短代码

在博客根目录新建：

```text
layouts/
└─ shortcodes/
   └─ webpage.html
```

`webpage.html` 内容：

```html
{{- $url := .Get "url" -}}
{{- $title := .Get "title" | default "网页预览" -}}
{{- $height := .Get "height" | default "800px" -}}

<div style="
  width: 100%;
  margin: 1.5rem 0;
  overflow: hidden;
  border: 1px solid #dcdfe6;
  border-radius: 8px;
  background: #ffffff;
">
  <iframe
    src="{{ $url | safeURL }}"
    title="{{ $title }}"
    loading="lazy"
    sandbox="allow-scripts allow-same-origin allow-forms allow-popups"
    style="
      display: block;
      width: 100%;
      height: {{ $height }};
      border: 0;
      background: #ffffff;
    ">
  </iframe>
</div>

<p style="font-size: 0.9rem;">
  如果网页无法显示，可以
  <a href="{{ $url | safeURL }}" target="_blank" rel="noopener noreferrer">
    在新窗口打开 {{ $title }}
  </a>。
</p>
```

不要修改：

```text
themes/blowfish/
```

自定义文件应该放在博客根目录的 `layouts` 中，这样更新 Blowfish 时不会被覆盖。[Blowfish 自定义说明](https://blowfish.page/docs/advanced-customisation/)

### 2. 在 Markdown 文章中使用

在文章正文中加入：

```markdown
## IPOK 在线检测

下面可以直接使用 IPOK 网站进行检测：

{{< webpage
  url="https://ipok.io/"
  title="IPOK IP 纯净度检测"
  height="850px"
>}}
```

或者写成一行：

```markdown
{{< webpage url="https://ipok.io/" title="IPOK IP 纯净度检测" height="850px" >}}
```

Hugo 官方将这种功能称为自定义 Shortcode，适合在 Markdown 中插入网页、视频和其他 HTML 内容。[Hugo Shortcode 文档](https://gohugo.io/content-management/shortcodes/)

### 3. 本地预览

在博客根目录运行：

```powershell
hugo server -D
```

浏览器访问：

```text
http://localhost:1313/
```

打开对应文章，就能看到嵌入的 IPOK 页面。Hugo 自动刷新仍然有效。

### 4. 部署

嵌入网页不需要把 `ipok.io` 下载到你的项目。正常部署 Hugo 即可：

```powershell
hugo --minify
```

如果你使用 GitHub Pages 自动部署，只需要提交以下两个文件：

```text
layouts/shortcodes/webpage.html
content/你的文章.md
```

部署以后，访问者看到的 IPOK 检测结果是**访问者自己的网络环境和 IP**，不是你的服务器 IP。

需要注意：外部网站可以通过 `X-Frame-Options` 或 CSP 禁止嵌入。如果本地预览出现“拒绝连接”或空白页面，这不是 Hugo 配置错误，而是 `ipok.io` 禁止 iframe。此时无法从你的博客强制绕过，只能保留“在新窗口打开”的链接。


明白，你说的是在文章中插入媒体内容。最适合做成两个功能：

* 图片：直接插入 Markdown。
* B站视频：插入 Hugo 短代码。

## 插入B站视频

建议创建一个专门的 B站短代码。

在博客根目录创建：

```text
layouts/
└─ shortcodes/
   └─ bilibili.html
```

内容如下：

```html
{{- $bvid := .Get "bvid" -}}
{{- $page := .Get "page" | default "1" -}}

<div style="
  position: relative;
  width: 100%;
  padding-bottom: 56.25%;
  margin: 1.5rem 0;
  overflow: hidden;
  border-radius: 8px;
  background: #000000;
">
  <iframe
    src="https://player.bilibili.com/player.html?bvid={{ $bvid }}&page={{ $page }}&autoplay=0"
    title="哔哩哔哩视频"
    scrolling="no"
    frameborder="0"
    allowfullscreen
    style="
      position: absolute;
      inset: 0;
      width: 100%;
      height: 100%;
    ">
  </iframe>
</div>
```

然后找到 B站视频地址，例如：

```text
https://www.bilibili.com/video/BV1AbCdEfGh/
```

其中：

```text
BV1AbCdEfGh
```

就是视频的 `BV号`。

在 Markdown 中插入：

```markdown
## 视频演示

{{< bilibili bvid="BV1AbCdEfGh" >}}
```

如果是视频的第二个分P：

```markdown
{{< bilibili bvid="BV1AbCdEfGh" page="2" >}}
```

这种方式不需要开启：

```toml
unsafe = true
```
